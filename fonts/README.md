# Шрифты

| Папка | Что внутри | В git и публичных сборках |
|---|---|---|
| `free/` | PT Sans, Inter, Manrope, Montserrat, Roboto, Space Mono — свободные лицензии, тексты лежат рядом (`OFL-*.txt`, `LICENSE-*.txt`) | да |
| `licensed/` | коммерческие шрифты, на которые у вас есть лицензия | **нет** (в `.gitignore`) |

Программа читает обе папки. Шрифты из `licensed/` в библиотеке помечены как
«лицензионные». Встроенный шрифт по умолчанию — PT Sans.

Чтобы пользоваться своими коммерческими шрифтами, положите файлы `.ttf`, `.otf` или `.ttc`
в `fonts/licensed/`. Шрифт можно и просто загрузить в программе на странице «Шрифты».

Сборки:

- `./scripts/release.sh` — только `free/`, такую сборку можно раздавать.
- `LICENSED=1 ./scripts/release.sh` — вместе с `licensed/`, только для владельца лицензий,
  не публиковать.
- Docker-образ копирует обе папки, поэтому его тоже не публикуйте, если `licensed/` не пуста.

ID встроенного шрифта не зависит от папки: если перенести файл между `free/` и
`licensed/`, документы не потеряют свои шрифты.
